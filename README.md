# College Management Information System (CMIS)

## Technologies Used
- Spring Boot
- React JS
- MySQL
- JWT Authentication
- Role-Based Access Control

## Features
- Student Registration with Register Number & Course
- Admin / Faculty / Student Roles
- Marks Management
- Fees Management
- Dashboard Analytics

## How to Run

### Backend
Run Spring Boot application on port 8080.

### Frontend
npm install
npm start
